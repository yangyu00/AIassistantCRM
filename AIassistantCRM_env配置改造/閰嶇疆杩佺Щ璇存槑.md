# 配置方式改造：YAML → .env

## 改了什么
| 原方式 | 新方式 |
|---|---|
| `config.yaml` + `config.py`（ImmutableYamlConfig） | `.env` + 重写后的 `config.py` |
| `IOP['TOKEN']['secret']` 等嵌套字典访问 | 同样支持嵌套访问，另加属性式 `config.IOP.TOKEN.secret` |
| 密码只能靠系统环境变量覆盖 | 直接写在 `.env`（系统环境变量优先级仍更高） |
| SFTP 连接参数写死在 `sftp_common/config.py` | 改读 `.env` 的 `SFTP_HOST/PORT/USERNAME/PASSWORD/RUNTIME_DIR` |

## 使用
```bash
pip install -r requirements.txt
cp .env.example .env   # 填 IOP_CLIENT_SECRET、SFTP_PASSWORD
python config.py       # 打印当前生效配置（密码打码），排查用
python main.py
```
Docker：`docker run --env-file .env ...`，不再需要逐个 `-e`。

## 优先级
系统环境变量 > `.env` 文件 > `config.py` 中 `DEFAULT_ENV` 兜底值。

## 改动文件
- `config.py`：重写，读取 `.env`；保留 `ImmutableYamlConfig` 别名，旧调用写法仍可用
- `main.py`、`IOP/get_token.py`、`IOP/get_custinfo.py`、`IOP/iop_client.py`、`src/log_util.py`、`test_local/test_iop.py`：改用 `from config import config`，去掉 `global_config = ...()` 实例化
- `sftp_common/config.py`：SFTP 连接参数改读配置
- `sftp_jobs/config.py`：`RUNTIME_DIR` 改读 `SFTP_RUNTIME_DIR`
- `requirements.txt`：pyyaml → python-dotenv
- 新增 `.env.example`；删除 `config.yaml`

## 注意
- `.gitignore` 原本已忽略 `.env`，无需再改
- 配置对象仍只读，运行期写入会抛 `RuntimeError`
- 业务表结构、产品ID 等属于代码级配置，仍留在 `sftp_jobs/config.py`，未搬进 `.env`
- 未改动的文件（services、scripts、sftp_common 其余模块等）与仓库原版一致
